CENTRAL DIGITAL SURVEY

Precision in Every Measurement.

A premium, responsive business website for Central Digital Survey, a digital land surveying and mapping company based in Trivandrum, Kerala, India.

🌐 About the Website

The website is designed with a modern royal-luxury appearance, combining deep navy blue, champagne gold, elegant typography and compass-inspired branding.

Its purpose is to introduce the company, showcase its surveying services and help potential clients contact the business.

✨ Features

- Premium royal-luxury design
- Responsive mobile-friendly layout
- Compass-inspired branding
- Professional homepage and company introduction
- Surveying services section
- Project showcase section
- Contact information section
- Direct WhatsApp enquiry button
- Click-to-call phone number
- Email enquiry link
- Smooth scrolling navigation
- HTML and embedded CSS in a single file

🛠️ Technologies Used

- HTML5
- CSS3
- Inline SVG graphics
- Responsive web design

No external CSS or JavaScript framework is required.

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. The website will run without installing additional software.

🌍 Deployment

This website can be hosted using GitHub Pages.

1. Upload "index.html" and "README.md" to your GitHub repository.
2. Open repository Settings.
3. Select Pages.
4. Choose the main branch as the publishing source.
5. Save the settings.
6. Open the generated GitHub Pages website URL.

A custom domain can also be connected later.
